# HSU(한성대) 팔레트

![HSU 팔레트 아이콘](./icons/icon128.png)

한성대학교 e-class의 화면 색상과 글꼴을 취향에 맞게 바꾸고 저장하는 Chrome 확장 프로그램입니다. 추천 프리셋을 선택하거나 영역별 색상을 직접 조합해 나만의 테마를 만들 수 있습니다.

- 설치: [Chrome 웹 스토어](https://chromewebstore.google.com/detail/hsu%ED%95%9C%EC%84%B1%EB%8C%80-%ED%8C%94%EB%A0%88%ED%8A%B8/clhpdcfmifehbciceddjcgiimnjflgad?hl=ko)
- 사용 사이트: [한성대학교 e-class](https://learn.hansung.ac.kr/)
- 소스 코드: [iamcode04/hsu-palette](https://github.com/iamcode04/hsu-palette)
- 버전: `1.1.3` (GitHub `main` 기준)
- 라이선스: [MIT](./LICENSE)

> 이 README는 GitHub `main` 브랜치의 소스 코드를 기준으로 작성했습니다.

## 제작 배경

기존 한성대학교 e-class의 밋밋한 배경을 바꾸고 싶어 만들었습니다. 화면의 색상뿐 아니라 글꼴도 바꿀 수 있도록 해, e-class를 내 취향에 맞는 모습으로 사용할 수 있도록 했습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 영역별 색상 변경 | 상단바, 배경, 카드 등 화면의 각 영역을 선택해 색상을 바꿀 수 있습니다. 현재 페이지에 존재하는 영역에 편집 표시가 나타납니다. |
| 색상 직접 선택 | 색상 선택기에서 색조·채도·밝기를 조절하거나 `#RRGGBB` 형식의 색상 코드를 입력할 수 있습니다. 지원하는 브라우저에서는 스포이드로 화면의 색을 선택할 수도 있습니다. |
| 글자색 선택 | 영역별로 자동, 흰색, 검정, 회색 중에서 선택할 수 있습니다. 자동 모드에서는 배경 밝기에 따라 글자색을 정합니다. |
| 추천 프리셋 | 미드나잇, 포레스트, 라벤더, 민트 등 30개의 색상 조합을 제공합니다. |
| 내 프리셋 | 현재 화면 유형의 배경색·글자색 조합을 최대 5개까지 저장하고 다시 적용하거나 삭제할 수 있습니다. |
| 색상 즐겨찾기 | 자주 사용하는 색상을 최대 10개까지 저장해 다른 영역에도 적용할 수 있습니다. |
| 글꼴 변경 | 기본 글꼴, Pretendard, 주아, 나눔스퀘어라운드 중에서 선택할 수 있습니다. 메인 화면과 강의 페이지에 함께 적용됩니다. |
| 화면별 테마 저장 | 메인 화면과 강의 페이지의 색상 설정을 각각 저장합니다. 강의 페이지 설정은 여러 강좌에서 공유됩니다. |
| 영상 창 색상 연동 | 강의 페이지에서 선택한 상단바 색상과 글자색을 영상 창의 상단 영역에도 적용합니다. |
| 색상 초기화 | 현재 화면 유형의 색상과 글자색 설정을 기본 상태로 되돌립니다. |

변경할 수 있는 영역은 **상단바, 아이콘바, 강의 배너, 메뉴 상자, 펼친 메뉴, 배경, 카드, 카드 제목, 버튼, 강좌 라벨, 진도 번호**입니다.

## 설치 방법

### Chrome 웹 스토어에서 설치

1. [HSU(한성대) 팔레트 설치 페이지](https://chromewebstore.google.com/detail/hsu%ED%95%9C%EC%84%B1%EB%8C%80-%ED%8C%94%EB%A0%88%ED%8A%B8/clhpdcfmifehbciceddjcgiimnjflgad?hl=ko)를 엽니다.
2. **Chrome에 추가**를 누르고 확장 프로그램 추가를 확인합니다.
3. [한성대학교 e-class](https://learn.hansung.ac.kr/)에 로그인하고 페이지를 새로고침합니다.

### 소스 코드로 설치

1. [GitHub 저장소](https://github.com/iamcode04/hsu-palette)에서 **Code → Download ZIP**을 선택합니다.
2. 다운로드한 ZIP 파일의 압축을 풉니다.
3. Chrome 주소창에 `chrome://extensions`를 입력하고 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 선택하고, `manifest.json`이 들어 있는 폴더를 지정합니다.
5. e-class 페이지를 새로고침합니다.

저장소의 원본 파일을 로드해 사용할 수 있습니다. 배포용 파일을 만드는 방법은 아래의 개발·빌드 안내를 참고해 주세요.

## 사용 방법

1. e-class 화면 **왼쪽 아래의 팔레트 버튼**을 누릅니다.
2. 바꾸고 싶은 영역의 이름을 눌러 색상 선택기를 엽니다.
3. 색상을 직접 고르거나 색상 코드를 입력하고, 필요한 경우 글자색도 선택합니다.
4. **프리셋**에서 추천 테마를 적용하거나 **내 프리셋 → + 지금 테마 저장**으로 현재 색상 조합을 저장합니다.
5. **폰트**에서 원하는 글꼴을 선택합니다.
6. 편집을 마치면 **완료**를 누릅니다.

색상과 글꼴 선택은 변경할 때 저장됩니다. **완료** 버튼은 편집 화면을 닫습니다.

메인 화면과 강의 페이지에 서로 다른 테마를 쓰고 싶다면 각각의 화면에서 편집합니다. **초기화**는 현재 화면 유형의 색상 설정을 되돌리며, 글꼴·즐겨찾기·내 프리셋은 유지합니다. 글꼴을 되돌리려면 **폰트 → 기본**을 선택합니다.

## 설정 저장과 적용 범위

- 테마, 색상 즐겨찾기, 내 프리셋과 글꼴 설정은 `chrome.storage.sync`에 저장됩니다. Chrome 동기화를 켠 환경에서는 같은 Chrome 계정의 브라우저 간에 설정이 동기화될 수 있습니다. 자세한 동작은 [Chrome 저장소 안내](https://developer.chrome.com/docs/extensions/reference/api/storage#storage-areas)를 참고해 주세요.
- 설정은 브라우저 확장 프로그램에 저장되며 e-class 로그인 계정별로 분리되지 않습니다.
- 테마 편집은 로그인 화면과 뷰어 화면을 제외한 e-class 페이지에서 제공됩니다. 뷰어에는 별도의 상단 영역 색상 적용 스크립트가 사용됩니다.
- 글꼴 변경 시 코드 표시 영역과 아이콘 글꼴 등 일부 요소는 원래 글꼴을 유지합니다.
- 스포이드 버튼은 브라우저에서 `EyeDropper` 기능을 지원할 때 표시됩니다.

## 개발 및 빌드

JavaScript, CSS와 Chrome Extensions Manifest V3를 사용합니다. 배포용 빌드는 **Node.js 20 이상**이 필요합니다.

저장소 폴더에서 다음 명령을 실행합니다.

```sh
npm ci
npm run build
```

빌드 스크립트는 JavaScript 번들링·압축과 CSS 압축을 수행하고, 아이콘·글꼴·외부 라이선스 고지를 복사합니다.

- `release/unpacked/`: 압축해제된 확장 프로그램으로 로드할 폴더
- `release/hsu-palette-1.1.3.zip`: 현재 소스 버전을 기준으로 한 배포용 ZIP

자세한 내용은 [BUILD.md](./BUILD.md)를 참고해 주세요. 소스를 수정한 뒤에는 `chrome://extensions`에서 확장 프로그램을 새로고침하고, e-class 페이지도 새로고침합니다.

`LICENSE`를 저장소에 추가한 뒤 배포 파일을 만들 때는 이 파일도 결과물에 포함해 주세요. 현재 `scripts/build.mjs`의 복사 목록에는 프로젝트 자체의 `LICENSE`가 포함되어 있지 않습니다.
